<h1>Contributing to Nether.js</h1>

<h2>Reporting issues</h2>
<p>If you find bug in nether.js you can report it in 2 ways</p>
<br>
<ul>
    <li>Create issue on github</li>
    <ol>
        <li>Go to [https://github.com/dqnx19/nether-js/issues](https://github.com/dqnx19/nether-js/issues)</li>
        <li>Click to "new issue"</li>
        <li>To title write "bug report"</li>
        <li>in description briefly describe the bug</li>
        <li>Click to "create"</li>
    </ol>
    <li>Write email</li>
    <ol>
        <li>Open your email client (outlook, gmail etc.)</li>
        <li>Click to new email</li>
        <li>To subject write "bug report"</li>
        <li>in message content briefly describe the bug</li>
        <li>Click to "send"
    </ol>
</ul>
<br>
<p>if it will be possible to contact you, you will be informed if your report is a bug or not and if yes you will be informed that it was fixed</p>
